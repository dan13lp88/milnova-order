# Online Ordering Demo

A Streamlit prototype for a small business to accept online pickup and delivery orders.

## Features

- Browse a sample menu
- Add products to a shopping cart
- View cart total
- Enter customer and fulfillment details
- Submit a demo order confirmation

## Run locally

### Prerequisites

- Python 3.10 or later
- Git

### Setup

```bash
git clone https://github.com/YOUR-GITHUB-USERNAME/online-ordering-demo.git
cd online-ordering-demo
python -m venv .venv
